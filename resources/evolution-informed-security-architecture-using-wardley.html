Evolution-informed Security Architecture: Using Wardley Mapping (SABSA)

Reference & derivative Unverified talk (security)

No screenshot. Either this resource is not in the 30-target capture set, or the capture returned an interstitial rather than the page — which is recorded as a failure rather than published as a screenshot. What was and was not captured.

What it is

The most institutionally serious treatment of Wardley mapping in security architecture — SABSA is an established enterprise security architecture framework with a formal certification track, and this webinar maps Wardley's technique onto it. Platt introduces mapping as a strategy-development framework and then demonstrates "how it can help inform decisions at different layers of the SABSA matrix," using climatic patterns and doctrine to help security architects spot risks and opportunities in enterprise security delivery. The significance is the direction of travel: rather than security people discovering mapping, this is an established security architecture body incorporating it.

Limitations

The recording is behind SABSA membership — you can cite the abstract but most readers cannot watch it. From 2020. A sibling SABSA URL is robots.txt-blocked, so verification is partial. Presupposes SABSA knowledge.
