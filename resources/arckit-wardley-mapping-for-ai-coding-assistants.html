ArcKit (Wardley mapping for AI coding assistants)

Tool Very active tool

What it is

An enterprise-architecture governance harness for AI coding assistants, with Wardley mapping as a first-class capability rather than an afterthought. It exposes a set of slash commands — /arckit:wardley to build a strategic map for component evolution analysis (Genesis → Custom → Product → Commodity), build-vs-buy and vendor comparison, plus specialised variants wardley.value-chain, wardley.doctrine, wardley.gameplay and wardley.climate that each drive a different part of the method. It vendors 147 Wardley maps in-repo as a reference corpus, so the assistant has grounded examples rather than hallucinating from memory. It installs across Claude Code (primary — 13 plugins via marketplace), Gemini CLI, GitHub Copilot (.prompt files), Mistral Vibe and Codex/OpenCode, and bundles MCP servers for AWS Knowledge, Microsoft Learn and Google Developer Knowledge.

Limitations

Wardley mapping is a feature of a much larger EA governance product — you take on a great deal of unrelated surface area to get it. Heavily oriented toward UK/enterprise governance concerns (jurisdictional overlays, G-Cloud). Very fast version churn (v0.3 → v5.15 in about a year) means documentation and blog posts go stale quickly. LLM-generated maps inherit all of Matt Edgar's "laundering assumptions into facts" critique, amplified — an agent will confidently place components on the evolution axis with no basis whatsoever.
